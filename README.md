## FAQ

### What is XCutors?

XCutors is a Windows desktop collection that bundles several popular Roblox script executors together with a universal loader called xcutorsLoader, giving you a single interface to manage and switch between them.

### Which executors are included?

The package includes Volt, Synapse Z, Potassium, Wave, and the universal xcutorsLoader that ties them all together.

### Is XCutors free to use?

Yes, the xcutorsLoader and the bundled executor tools are completely free to download and use.

### What operating systems are supported?

XCutors currently supports Windows 10 and Windows 11 (64-bit). macOS and Linux are not supported at this time.

### Do I need to disable my anticomponent?

Some anticomponent programs may flag executor files as false positives because they interact with other processes. You should add the XCutors folder to your anticomponent exclusion or whitelist rather than fully disabling protection.

### Can I use my own custom Lua scripts?

Absolutely. You can paste scripts directly into the built-in editor, load them from local .lua or .txt files, or pick scripts from the included community script hub.

### How do I update the executors?

The xcutorsLoader includes an auto-update feature. When you launch it, it checks for newer versions of each executor and prompts you to download and apply updates with a single click.

### Is there a script hub included?

Yes, XCutors ships with a built-in script hub containing a curated selection of popular community scripts organized by game and category.

### Why does injection fail or Roblox crashes?

Injection issues are usually caused by an outdated executor version after a Roblox update, missing administrator privileges, or anticomponent interference. Make sure you are running the latest release as administrator and have added the folder to your exclusion list.

### Can I run multiple executors at the same time?

It is recommended to use only one executor per Roblox instance. However, xcutorsLoader supports multi-instance Roblox sessions, each with its own independent executor.
